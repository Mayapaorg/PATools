# PATools

Public tooling for Maya Domme-PA workflows.

## Purpose
Scripts and helpers that support training ops without holding private trainee data:
- Bluesky / repo helpers
- Scrubbing / export utilities
- Future Jules-driven automation targets

## Not here
No vault media, journals, contracts, or personal identifiers. Those stay in `PAWorkprivate`.

## Tools
- [`gmx-mail/`](gmx-mail/) — GMX mailbox CLI, Python client, and local HTTP bridge (IMAP/SMTP)

## Related
- [`PAWorkpublic`](https://github.com/Mayapaorg/PAWorkpublic) — scrubbed doctrine
- [`PAWorkprivate`](https://github.com/Mayapaorg/PAWorkprivate) — private vault (restricted)
